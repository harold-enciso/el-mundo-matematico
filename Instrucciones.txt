Crear entorno virtual (solo la primera vez):
python -m venv env

Activarlo (en CMD):
cd env
cd Scripts
activate.bat

Activarlo (en Powershell):
cd env
cd Scripts
.\Activate.ps1

Instalar las librerias (solo la primera vez):
pip install fastapi uvicorn

Seleccionar interprete python en vscode:
Ctrl+Shift+P
